# Changelog

## 1.3.1 — 2026-10-17

### Исправления

- `WPT.exe` из релиза падал при старте (XamlParseException): теперь self-contained single-file, .NET и Windows App Runtime ставить не нужно
- Повторный запуск показывает окно уже запущенного WPT (в том числе из трея) вместо тихого выхода
- Обычный запуск при уже запущенном от администратора WPT больше не оставляет висящий процесс без окна
- Флаг `--elevated` в WinUI не распознавался

## 1.3.0 — 2026-07-30

### Новое

- **WinUI 3** — основной клиент (`WPT.exe`), WPF сохранён как альтернатива (`WPT WPF.exe`)
- Общие ViewModels и UI-хост для обоих фронтендов

### Улучшения

- Единая папка `release/` и скрипт `tools/publish-release.ps1`
- Обновлённая иконка приложения

## 1.1.7 — 2026-07-05

### Новое

- Импорт конфигураций **AmneziaWG** (`.conf`) на вкладке «Прокси» — файл или перетаскивание, сохранение в общий список, запуск локального прокси

### Улучшения

- Окно не зависает при старте, при запуске/остановке прокси и при включении/отключении PAC
- Кнопка прокси показывает «Запуск...» / «Остановка...» на время операции
- Проверка прокси не застревает в «Проверка» дольше 12 секунд
- Пинг скрыт для VPN-конфигов Amnezia
