# Changelog

## 2.1.0 — 2026-11-11

### Новое

- **Process Mode: выбор из запущенных приложений.** Кнопка «Из запущенных» рядом с полем ввода открывает список приложений текущего сеанса с иконками; системные процессы Windows, службы и компоненты самого WPT в список не попадают

## 2.0.1 — 2026-11-10

### Исправления

- `WPT.exe` падал при старте, если файл переименован (например, «WPT (1).exe» после повторного скачивания)

## 2.0.0 — 2026-11-10

### Новое

- **Process Mode через AmneziaWG**: в списке конфигураций Process Mode теперь есть сохранённые AWG-конфиги, TCP и UDP выбранных приложений уходят в туннель AmneziaWG. Перед wireproxy стоит sing-box со sniffing, поэтому работает и при fake-IP/подменённом DNS (198.18.x.x)
- **Списки доменов через прокси**: если GitHub и jsDelivr недоступны напрямую, списки скачиваются через любой работающий локальный прокси (вкладка «Прокси» или Process Mode). Пока списков нет, на вкладке туннелирования висит плашка; нажатый без списков «Применить» доводится до конца после скачивания; при старте прокси поднимается до загрузки списков; таймауты прямой загрузки сокращены до 30 с

### Исправления

- wireproxy обновляется до awg-wireproxy 2.1.0+ (UDP через SOCKS5, AmneziaWG 2.0/3.x); установка снова работает — с 2.1.0 сборки выкладываются в `.zip`
- Конфиги AmneziaWG 3.x с `RandomTrailers = on` / `DisableCookies = on` больше не отклоняются wireproxy
- Проверка локального порта больше не пишет в лог ложное «Необработанное исключение фоновой задачи»

## 1.3.1 — 2026-10-17

### Исправления

- `WPT.exe` из релиза падал при старте (XamlParseException): теперь self-contained single-file, .NET и Windows App Runtime ставить не нужно

- Обычный запуск при уже запущенном от администратора WPT больше не оставляет висящий процесс без окна
- Флаг `--elevated` в WinUI не распознавался
